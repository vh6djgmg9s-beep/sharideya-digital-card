# Запись NFC-метки SHARIDEYA

## До записи

Публикация ещё не выполнена. Не записывайте localhost или предполагаемый адрес. Сначала завершите публикацию из README. После её проверки сборка создаст в `docs/`:

- `NFC_URL.txt` — реальный HTTPS-адрес;
- `NFC_URI.ndef` — одна NDEF-запись Well Known URI (TNF=1, тип U/0x55, HTTPS prefix=0x04);
- `NFC_TYPE2_TLV.bin` — NDEF в TLV-контейнере Type 2, для технических инструментов. Это НЕ полный дамп метки: нельзя записывать его поверх служебных страниц/UID/lock bits.

Проверка размера ограничивает запись вместимостью NTAG213 (144 байта пользовательской памяти); короткая запись подходит также для NTAG215 и NTAG216. Используйте исправную, доступную для записи NDEF-метку. Не блокируйте её навсегда до окончания физических проверок.

## Android

1. Установите NFC Tools от wakdev из официального магазина; включите NFC в настройках телефона.
2. Откройте NFC Tools → «Запись» / Write → «Добавить запись» / Add a record → «URL / URI».
3. Вставьте весь адрес из `NFC_URL.txt`. Если приложение выделяет протокол отдельным полем, выберите `https://` и не дублируйте его в адресе.
4. В списке должна быть одна запись URL. Нажмите «Запись» / Write и приложите метку к NFC-антенне телефона. Дождитесь сообщения об успехе.
5. В разделе «Чтение» / Read прочитайте метку и сравните адрес с `NFC_URL.txt`.

## iPhone

1. Установите NFC Tools от wakdev. На проверенной странице разработчика для текущей версии указаны iPhone XS/XR или новее и iOS 17; сверяйте требования App Store на устройстве.
2. Откройте Write → Add a record → URL / URI, добавьте HTTPS-адрес из файла.
3. Нажмите Write и поднесите верхнюю часть iPhone к метке. Не убирайте телефон до подтверждения.
4. Прочитайте метку в Read и проверьте точное совпадение URL.

Названия пунктов могут немного отличаться в зависимости от языка и версии NFC Tools. Не нужны раздел Tasks, NFC Tasks или платные функции: записывается обычная URL-запись.

## Проверка клиентского сценария

Закройте NFC Tools. На совместимом телефоне с включённым экраном поднесите NFC-антенну к метке. Нажмите системное уведомление, если оно появится: должна открыться HTTPS-визитка. Проверьте WhatsApp, звонок, Instagram, скачивание/импорт VCF, оба QR другой камерой. Повторите на iPhone и Android. Для открытия сайта нужен интернет. Чтение зависит от модели телефона, настроек NFC и расположения антенны; металлическая поверхность может потребовать специальной on-metal метки.

У клиента специальное приложение для обычного открытия URL на совместимом телефоне не требуется. Сам сайт не использует Web NFC и не записывает метку из браузера.

**Физическая метка не записана и не проверена агентом.** Успешные автоматические проверки файлов не подтверждают работу конкретного чипа и смартфона.
