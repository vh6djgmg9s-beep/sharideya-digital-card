# Результаты проверки

Локальная статическая визитка протестирована Playwright в Microsoft Edge (headless).

## Выполнено

- `npm run build`: сборка HTML/CSS/JS, VCF, контактного QR PNG, изображения SVG и PNG.
- `npm run lint`: проверка синтаксиса JavaScript.
- `npm test`: 18 проверок, включая ширины 320, 375, 390, 430, 768 и 1280 px. Нет горизонтального переполнения; основные кнопки не меньше 44 px по высоте.
- Контактный QR программно декодирован jsQR; содержимое побайтно соответствует VCF.
- Проверены vCard 3.0, CRLF, название, телефон, город, страна, WhatsApp и Instagram.
- Скачивания VCF и PNG реально выполнены в браузере, содержимое файлов проверено.
- Проверены успешная передача данных в Web Share API, отмена, ошибка, копирование в буфер, ручное копирование при отказе буфера. Web Share и clipboard API подменены в тесте; реальные системные окна не проверялись.
- Проверены фактические значения href телефона, WhatsApp и Instagram, `noopener noreferrer`. Реальный звонок/отправка сообщения не выполнялись.
- Основные контактные ссылки и QR доступны с отключённым JavaScript.
- В браузерных проверках не обнаружены ошибки JS/CSP, ответы HTTP >=400 и запросы к внешним доменам.
- `npm install` выполнил аудит: 0 известных уязвимостей (34 пакета с учётом корневого проекта).
- Визуально осмотрены мобильный снимок 390 px и экспорт PNG; после осмотра устранён отступ по краям изображения и заменена иконка телефона.

Подробные результаты с фактическим временем запуска: `artifacts/test-results.json`. Снимки всех размеров: `artifacts/viewport-*.png`.

## Не завершено

- Создание публичного GitHub-репозитория и публикация Pages: требуется вход пользователя в GitHub.
- Финальные QR PNG/SVG с публичным URL, NFC_URL.txt и NDEF: генерируются только после проверки опубликованного HTTPS-адреса, пока отсутствуют.
- Декодирование финального URL-QR и сравнение с опубликованным адресом: ещё не выполнено. Тест реализован и автоматически запускается после финализации URL.
- Проверка опубликованных ресурсов: `node scripts/verify-live.mjs`, ещё не выполнялась.
- Физическая запись/чтение NFC и импорт контакта на реальном iPhone/Android: не выполнялись.

Публичный адрес не предполагается и не объявляется действующим. До публикации QR на экспортируемом изображении содержит сам контакт, а не URL сайта; после финализации изображение автоматически получает QR публичного сайта.
